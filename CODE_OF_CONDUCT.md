# Code of Conduct

## Our Pledge

We expect contributors to treat each other with respect and professionalism.

## Our Standards

Examples of behavior that helps create a healthy project:

- Clear, factual communication
- Respect for different experience levels
- Willingness to explain tradeoffs and fix mistakes
- Focus on the code and the work, not the person

Examples of behavior that does not belong here:

- Harassment, insults, or intimidation
- Personal attacks
- Deliberate derailment or bad-faith behavior
- Sharing private information without permission

## Enforcement

Project maintainers may remove comments, close issues, or reject contributions that violate this code of conduct.

## Scope

This code applies to project discussions, pull requests, issues, and other project spaces.
